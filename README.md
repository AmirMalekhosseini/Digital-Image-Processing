## HW4
**[Notebook](HW4/HW4.ipynb)**  
This assignment explores advanced morphological image processing techniques:
- **Dilation and Erosion:** Custom implementations for basic morphological transformations.
- **Noise Reduction:** Removing salt-and-pepper noise using opening and closing.
- **Parallel Line Extraction:** Extracting vertical and horizontal lines using oriented structuring elements.
- **Edge Detection:** Using morphological gradients to detect edges in images.
- **Counting Objects:** Practical example of counting coins using morphological operations.

_This notebook demonstrates the power of morphology in cleaning, segmenting, and analyzing digital images._
